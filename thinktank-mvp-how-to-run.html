Every Time You Want to Run ThinkTank

Do these two steps in order — both take about 5 seconds.

1 Start Ollama Do this first

Open the Ollama app from your Start menu — look for the llama icon in your system tray (bottom-right of taskbar). If it's already there, skip this step.

Or start it manually in any terminal:

ollama serve
Leave this terminal open. Ollama must be running for AI features to work.
2 Launch ThinkTank Open a new terminal

Open a new terminal (Command Prompt or PowerShell), then run:

cd "C:\Users\ChrisDovico\Desktop\ThinkTank MVP"
python -m streamlit run app.py

Your browser will open automatically at:

http://localhost:8501
Keep this terminal open while using ThinkTank. Press Ctrl+C to stop it when done.

What Each Tab Does

💡
Ideas
Create ideas, run Rapid Bounce (wild / balanced / conservative reframes + experiments)
🔬
Analysis
Refine into milestones, Score (impact/effort/risk/novelty), Critique for failure modes
🚦
Gate
Go / No-Go verdict — ✅ PROCEED, ⚠️ CAUTION, or ❌ STOP with full audit trail
💬
Ask
Multi-turn chat assistant with persistent memory stored locally in SQLite
⚙️
Admin
Ollama health check, DB stats, full config view, gate history log

Quick First-Run Walkthrough

  • Go to the ⚙️ Admin tab → click Check Ollama → should say ✅ Ready
  • Go to the 💡 Ideas tab → type an idea → click Save + Rapid Bounce
  • Go to 🔬 Analysis → click Score then Critique
  • Go to 🚦 Gate → click Run Gate → see your Go/No-Go verdict
  • Go to 💬 Ask → type any question → hit Enter

Troubleshooting

❌ "Cannot reach Ollama" error in the app
Ollama isn't running. Open the Ollama app from Start menu or run ollama serve in a terminal, then try again.
❌ Browser doesn't open automatically
Manually navigate to http://localhost:8501 in any browser.
❌ "streamlit is not recognized" error
Run python -m streamlit run app.py instead of just streamlit run app.py.
❌ AI responses are slow
Normal on first call — llama3.2 loads into memory (~5–10s). Subsequent responses are faster. Close other heavy apps to free RAM.
❌ Want to use a different AI model
Run ollama pull mistral (or any model), then open thinktank/config.py and change OLLAMA_MODEL = "mistral".
